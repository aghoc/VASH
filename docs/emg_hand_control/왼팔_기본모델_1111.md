## 2. 오늘 밤 녹화 (기본 모델용, 착용 1 번에 약 20 분)
pc_tools 터미널(.venv)에서 실행합니다. 앱은 근전도를 끈 상태여야 COM6 을 씁니다.
착용 이름은 밴드를 찰 때마다 새로 짓습니다 (예: 20261111c, 다시 차면 20261111d).

```
python rec_right.py CAL   20261111c left    # 평소 정밀 보정 자세, 7 동작 2 회 (90 s)
python rec_right.py TRANS 20261111c left    # 전환 (2 분)
python rec_right.py FWD   20261111c left    # 팔을 앞으로 뻗어 어깨 높이 (90 s)
python rec_right.py UP    20261111c left    # 팔꿈치 90° 접어 손이 위로 (90 s)
python rec_right.py DOWN  20261111c left    # 11-12 추가: 팔꿈치 90°, 손바닥이 바닥 (엎침) (90 s)
python rec_right.py SIDE  20261111c left    # 11-12 추가: 팔꿈치 90°, 엄지가 위 (90 s)
python rec_right.py PINCH 20261111c left    # 집기와 손 펴기·세손가락·가위·검지를 서로 바로 바꿈 (약 4 분)
python rec_right.py TEST  20261111c left    # 시험: 쉬는 동작 (2 분)
python rec_right.py CHAIN 20261111c left    # 시험: 연속 동작 (1 분)
python grip_model.py --arm left addwear --session 20261111c
```
- 녹화 원칙:
  - FWD·UP 은 쉬는 동안에도 팔을 그 자세로 둡니다. 휴식도 그 자세에서 배워야 오작동이 줄어듭니다.
  - 밴드를 한 번 풀었다가 다시 차서 한 착용 더 녹화하면 더 좋습니다. 착용마다 위치 차이를 배우기 때문입니다.
- 모두 끝나면:
  ```
  python grip_model.py --arm left rebuild-base     # 왼팔 기본 + SVM 표본 (착용 10 개 이상, 몇 분)
  ```
- 내일: 앱 [위치 확인] → 정밀 보정 → SVM 자동 선택 → [분류 확인].

## 3. 착용 위치: 왜 반 칸씩 옮겨도 안 맞았나
- **같은 자리에서도 차고 바로는 무늬가 바뀝니다.** 오늘 왼팔(20261111b)을 마지막 정밀 보정 무늬와 비교한 값입니다. 가장 맞는 회전은 내내 0 칸이었습니다.

  | 녹화 (시각) | 일치도 |
  |---|---|
  | 위치 확인 (18:15, 18:18) | 0.75 · 0.70 |
  | 보정 1 (18:20–18:22) | 0.78 → 0.84 |
  | 보정 2 (18:24) | 0.97 |
  | 전환 (18:27) | 0.97–1.00 |

  - 18:20–18:22 는 밴드를 건드리지 않은 한 녹화 안에서 오른 값입니다.
  - 바뀐 것은 일부 채널의 세기입니다 (CH5 16→26 µV, CH7 16→6 µV). 채널 전체가 옆으로 밀린 회전이 아닙니다.
- **예전 판정의 문제:** 0 칸 0.74, +1 칸 0.66 처럼 옆 칸이 낮아도 포물선 계산 때문에 '새끼 쪽으로 반 칸' 이 나왔습니다. 이 안내대로 돌리면 오히려 맞던 자리에서 벗어납니다.
- **새 판정:**
  - '돌리세요' 는 옆 칸이 0.08 이상 분명히 더 맞을 때만, 한 칸 단위로 안내합니다.
    - 채널을 일부러 1 칸 돌린 녹화는 옆 칸이 0.6 넘게 더 맞아 바로 잡힙니다.
    - 같은 착용 안에서 흔들리는 폭은 0.02–0.08 입니다.
  - 0.85 이상이면 좋음입니다.
  - 0.75–0.85 면 '돌리지 말고 정밀 보정' 입니다. 정밀 보정이 그 자리에 맞춰 줍니다.
  - 0.75 아래인데 회전이 아니면 1–2 분 주먹·손 펴기를 몇 번 한 뒤 다시 확인하고, 그래도 낮으면 다시 찹니다.
- **피부가 돌아가는 문제 (해부):**
  - 아래팔을 엎치고 뒤칠 때 척골은 거의 그대로 있고, 요골과 그 위 근육이 척골 둘레를 돕니다.
  - 그래서 척골 능선은 좋은 기준점입니다. 다만 밴드가 붙은 피부는 근육 위로 몇 mm 미끄러집니다.
  - 따라서 착용, 위치 확인, 정밀 보정을 **같은 팔 자세**에서 합니다. 엄지를 나에게, 팔꿈치 90° 로 맞췄다면 녹화도 그 자세로 합니다.
  - 차고 난 뒤 밴드를 돌려 맞추지 않습니다. 다시 맞출 때는 풀고 다시 찹니다.
  - 차고 2–3 분 손을 몇 번 쥐었다 편 뒤 [위치 확인] 을 합니다.
- **팔을 앞으로 뻗거나 팔꿈치를 접어 들면 인식이 떨어지는 이유:**
  - 팔 무게를 버티느라 아래팔 근육(팔꿈치를 굽히는 위팔노근, 손목 펴는 근육)이 쉬는 동안에도 켜져서, 같은 손동작이라도 무늬가 달라집니다.
  - 지금 모델은 이 자세를 한 번도 배운 적이 없습니다. 그래서 FWD·UP 녹화를 기본 모델에 넣습니다.
  - 얼마나 나아지는지는 오늘 밤 녹화 뒤 재생으로 확인합니다 (아직 숫자 없음).
