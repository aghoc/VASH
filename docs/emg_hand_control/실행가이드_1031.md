## 자주 쓰는 조절 값 (터미널 B 명령 끝에)
| 옵션 | 기본 | 뜻 |
|---|---|---|
| `--open-window` | 1.5 | 손 펴기 뒤 이 시간 안의 주먹 = 감싸 쥐기 |
| `--wrap-rel-hold` | 0.5 | 풀 때 엄지 벌린 채 머무는 시간 s (물체 끼면 ↑) |
| `--wrap-unwind` | 0.9 | 거꾸로 푸는 전체 시간 s (느리면 ↓) |
| `--wrap-rel-thumb` / `--wrap-rel-fingers` / `--wrap-rel-delay` | 0.7 / 0.5 / 0.2 | 감싸 쥐기 풀 때 엄지·손가락 속도, 손가락 늦춤 |
| `--thumb-open-boost` | 1.0 | 다른 동작 펼 때 엄지 속도 |
| `--auto-close` | 0.9 | 쥐기 닫는 시간 s (0 = 이전 세기 비례 방식) |
| `--i-light` | 200 | 살살 전류 mA (물체가 빠지면 ↑) |
| `--i-contact` | 160 | 닿음 판단 전류 mA |
| `--slip-n` | 5 | 미끄러짐 판단 횟수 (0 = 반사 끄기) |

근전도 쪽 (터미널 A `run` 명령 끝에): 모드 모델 두 개를 쓸 때만 `--switch enter` (빈 Enter 로만 전환)
