# 통합 앱(비전 + 근전도) 적용 가이드 — 11-11 근전도 변경

**이 문서를 읽는 AI 에게:** 제슨에서 쓰는 앱은 다른 노트북에서 만든 **비전 + 근전도 통합 앱**입니다.
`src/emg_hand_control/emg/app/` 의 근전도 앱은 정현 전용 개발 앱이고 제슨에서는 쓰지 않습니다.
그래서 아래 항목은 통합 앱에 **같은 동작으로 직접 넣어야** 합니다. 근전도 계산 코드(`emg/grip_model.py`, `emg/grip_rt.py`, 모델 파일)는 저장소 것을 그대로 쓰고, 앱 쪽에서는 **명령을 부르는 방식과 화면만** 맞추면 됩니다.

다 넣은 뒤에는 맨 아래 '확인' 을 해 보고, 결과와 바꾼 파일을 `변경기록_및_오류대처.md` 맨 위에 적어 주세요.

## 꼭 넣을 것 (우선순위 순)

### 1. 모델은 메인 2 개만, 기본 선택은 SVM
- 모델 목록: `emg/data/S01/grip7_main_svm.pkl` ('VASH SVM (메인)'), `grip7_main_lda.pkl` ('VASH LDA (메인)') **두 개만** 보여 줌. `models_old/` 와 다른 `grip7_*.pkl` 은 보이지 않게.
- 정밀 보정이 끝나면 **SVM 을 자동 선택**. (재생 349 회: SVM 343 / LDA 311. 의수 거치대 착용에서도 SVM 이 위)
- 근전도 실행: `grip_rt.py run --model data/S01/grip7_main_svm.pkl --port <근전도 포트> --udp 127.0.0.1:9000 --log RUN{n}_emg.csv --save-raw RAW{n}.csv`
  - SVM 이면 `--svm-temp 1.5` 를 줘도 되고 안 줘도 됨 (모델 안에 1.5 저장)

### 2. 정밀 보정의 마지막 단계 (모델 만들기)
기존: 보정할 때마다 `grip7_<착용>.pkl` 같은 새 파일을 만듦 → **하지 말 것.**
대신 보정 녹화(CAL)와 전환 녹화(TRANS)가 끝나면 아래 명령을 부른다. `emg/` 폴더에서 실행하고, 끝나면 exit 0 이다.
```bash
python grip_model.py --arm right reinforce --session <착용 이름> --cal <마지막 CAL.csv> --trans <마지막 TRANS.csv> --no-base
```
- 약 40 초. `grip7_main_lda.pkl`, `grip7_main_svm.pkl` 을 덮어쓰고, 이전 것은 `data/S01/models_old/<이름>_<시간>.pkl` 로 남는다.
- 착용이 `data/S01/wears_right.json` 에 추가된다. 제슨에는 녹화 원본이 없으므로 이 파일의 제슨 쪽 변경은 **GitHub 에 올리지 말 것.**
- 출력에서 쓸 줄
  - `보정 저장 ...grip7_main_lda.pkl` (LDA 저장됨)
  - `SVM 모델 저장 ...grip7_main_svm.pkl` (끝)
  - 경고 줄 (`위치 ...`, `휴식 잡음 큼: CHx, ...`, `신호 약함: CHx ...`, `60 Hz ...`): 화면에 보여 준다.
- (선택) 끝난 뒤 `python grip_model.py --arm right rebuild-base` 를 뒤에서 실행해도 된다. 제슨에는 녹화 원본이 없어 `※ 녹화 원본이 없는 착용 ... → 기본 모델 그대로` 라고 바로 끝난다. 안 불러도 된다.

### 3. '거치대 착용' 체크 (정밀 보정·위치 확인에 같이 쓰임)
의수 거치대가 팔 아래에 달려 위쪽 전극 **CH5·CH6·CH7 이 늘 눌린다.** 그래서 이 채널의 잡음·약한 신호 경고와 위치 경고가 매번 뜬다. 체크하면:
- 녹화 전 접촉 확인: 경고 문장 안의 채널(`CH(\d)`)이 **모두 5·6·7 안에 있으면** 그 경고는 묻지 않는다.
- 보정 품질 경고 (위 2 의 경고 줄): `위치 ` 로 시작하는 줄, 그리고 문장 안 채널이 모두 5·6·7 인 줄은 뺀다. 남은 줄 중 '쓰지 말 것' 이나 '많이 어긋남' 이 있을 때만 '심각'.
- 위치 확인 명령에 `--skip-ch 5,6,7` 을 붙인다 (아래 4).
- 참고 구현: `emg/app/server.py` 의 `mount_filter()`, `MOUNT_CH`.

### 4. [위치 확인] 버튼 (착용 직후, 약 30 초)
1. 녹화: `finger_test.py record` 를 정밀 보정 녹화와 같은 공통 인자로 부르고, 아래만 바꾼다.
   - `--task PLACE --gestures "손 펴기,주먹,가위,검지 펴기,엄지 펴기" --reps 1 --hold 2.5 --rest 2 --relax --out data/S01/PLACE_<착용>_<시각>.csv`
   - 공통 인자: `--port --ch 1-8 --side band --subject S01 --session --arm right --seed`
2. 판단 (거치대 착용이면 `--skip-ch 5,6,7`):
   ```bash
   python grip_model.py --arm right placecheck <PLACE.csv> --model data/S01/grip7_main_svm.pkl [--skip-ch 5,6,7]
   ```
3. 출력 줄을 그대로 보여 준다. 첫 줄(`착용 위치 일치도 ... (회전 ...)`)은 빼도 된다. 예:
   - `위치 좋음 (일치도 0.92) — 그대로 정밀 보정하세요`
   - `밴드를 엄지 쪽으로 블록 1 개만큼 돌리세요 (CH1 블록이 지금 CH2 블록 자리로 가게) — 그러면 일치도 약 0.95`
   - `CH3: 휴식 잡음 21 µV (기준 4) — 전극을 눌러 붙이거나 다시 끼우기`
- 기준 = 메인 모델 안의 `place_ref` (마지막 정밀 보정의 채널 무늬). 녹화 원본이 없어도 된다.

### 5. [분류 확인] 버튼 (정밀 보정 뒤, 약 40 초)
1. 녹화: 공통 인자에 아래만 바꾼다. 7 동작은 정밀 보정과 같은 목록이다.
   - `--task CHECK --gestures "손 펴기,주먹,집기 (중지 펴기),세손가락 (중지 굽힘),가위,검지 펴기,엄지 펴기" --reps 1 --hold 2 --rest 2.5 --relax --rest-jitter 0.5 --next-cue 1 --out data/S01/CHECK_<착용>_<시각>.csv`
2. 판단: 모델은 지금 선택된 메인 모델이다.
   ```bash
   python grip_model.py --arm right classcheck <CHECK.csv> --model <선택한 메인 모델>
   ```
3. 출력: `분류 확인: 7/7 맞음`, 동작별 `맞음 가위 (도중에 검지 펴기 잠깐), 642 ms`, 마지막 `→ 잘 됨. 그대로 사용` 같은 안내. 그대로 보여 준다.

### 6. 근전도 보드·포트를 같이 쓰는 작업은 하나씩
위치 확인·분류 확인·정밀 보정·근전도 실행은 모두 근전도 포트를 쓴다. 실행 중이면 다른 것은 막는다 (지금 앱과 같음).

- SVM 모델에 2차 판단(experts) 붙이기 (11-10 실사용에서 더 나빴음, 코드에서 꺼 둠)
- 제슨에서 만든 `wears_right.json`·메인 모델·녹화 원본을 GitHub 에 올리기 (근전도 녹화 원본은 개인 데이터)

## 확인 (넣은 뒤 이 순서로)
1. 모델 목록이 메인 2 개뿐인지
2. 정밀 보정 끝 → 1 분 안쪽 → SVM 이 선택됐는지. `models_old/` 에 이전 메인이 생겼는지
3. 거치대 착용 체크 → CH5–7 만의 경고 팝업이 안 뜨는지 (CH1–4·CH8 경고는 뜸)
4. [위치 확인] → '위치 좋음' 또는 돌릴 방향이 나오는지
5. [분류 확인] → 'N/7 맞음' 과 동작별 줄이 나오는지
6. 근전도 실행 → 휴식 5 초 뒤 동작이 나오는지

참고: 정현 노트북에서는 녹화·신호만 가짜로 바꾸고 저장소 구성 그대로 2–5 를 돌려 통과했다 (정밀 보정 53 s, 위치 확인 0.97, 분류 확인 8/8). 실제 보드와 제슨으로는 아직 확인하지 않았다.
