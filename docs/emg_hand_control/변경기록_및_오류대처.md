## 오류 대처

| # | 증상 (터미널 출력) | 원인 | 할 일 |
|---|---|---|---|
| 1 | `ID 14: neutral waypoint outside calibrated motor limits` 또는 `캘리브레이션 범위 밖` | 손을 다른 컴퓨터에서 쓰거나 장력을 바꾼 뒤라 `calibration.yaml` 이 지금 손과 안 맞음 | 그 컴퓨터에서 앱 [장력·캘리브레이션] 또는 `start_hand.py --calibrate --calibrate-only`. 줄을 새로 갈았으면 `--update-baseline` |
| 2 | `중립 도착 실패 — 많이 벗어남 ['ID 14 3.4°']` | 옛 `start_hand.py` (한도 일괄 3°). ID 14(엄지 벌림)는 범위가 좁아 걸림 | 최신 `start_hand.py` (모터별 한도) 인지 확인. 11-10 에 옛 버전으로 되돌렸다가 이 오류가 다시 나서 최신으로 되돌림 |
| 3 | `Motor ID 7 is out of bounds ... Offsets: {7: 6.28...}` | 모터 전원을 껐다 켜면 여러 바퀴 위치가 한 바퀴(2π) 차이 날 수 있음. 코드가 자동으로 보정 | 정상. 그 뒤 `캘리브레이션 파일 정상` 이면 그대로 진행 |
| 4 | `motor bus returned no status packets` → `ClearCommError ... 액세스가 거부` → `Torque release unconfirmed` | U2D2 USB 통신이 순간 끊김 (원인 확정 안 됨). 11-09 두 번 모두 노트북이 배터리로 돌 때였고, USB 선택적 절전이 켜져 있었음 | ① 노트북은 충전기 연결 ② U2D2 는 허브 없이 본체 포트, 짧은 케이블 ③ Windows: 전원 옵션 → USB 선택적 절전 '사용 안 함' ④ 모터 전원·접지 확인 ⑤ 끊긴 뒤에는 **토크가 켜진 채 남을 수 있음** → 다음 실행 전에 토크 확인 |
| 5 | `hold_tension.py: 다른 프로그램이 모터를 쓰고 있어요 (토크가 켜져 있음)` | 앞 실행이 비정상 종료되어 토크를 못 끔 | 손을 쓰는 프로그램이 없는지 확인한 뒤 모터 16 개 토크만 끄고 다시 실행 |
| 6 | `ID 12: ... error=128` (Hardware Error Status 32 = 과부하) | 소지 MCP 가 걸린 채 계속 밀림 (11-09 세손가락 데모 중, 원인 미확인) | ID 12 Reboot 명령으로 오류 지움. 다시 나면 세손가락에서 약지·소지 squeeze 빼기 |
| 7 | `did not settle within 5s ... continuing` (경고) | 장력 때문에 중립에 조금 덜 감. 오류 아님 | 그 아래 `fault=0` 이고 한도 안이면 그대로 진행 |
| 8 | 앱 모델 목록에 모델이 없음 | 모델 파일이 `.gitignore` 때문에 안 올라왔거나 `models_old/` 에만 있음 | `emg/data/S01/` 에 `grip7_장착_svm_1109.pkl`, `grip7_미장착_lda_1108.pkl` 이 있는지 |
| 9 | 밴드를 다시 찬 뒤 인식이 나쁨 | 착용 모델은 그 착용 전용 | 앱 정밀 보정 다시. 거치대를 달고 쓸 거면 거치대 단 채로 보정 |
