# 동작 도중 다른 동작이 끼어들 때 (11-12)

정현: '흐름이 시작하면 한 덩어리로 보고, 다른 동작이 끼어들면 오류가 뜸'

## 원인 (`emg_bridge_guarded.py` Composer)
- **세손가락:** 다른 동작이 확정돼도 세손가락 풀기(0.6 s)와 마지막 머묾(0.15 s)을 다 마친 뒤에야 새 동작을 받음. 그동안 들어온 동작은 무시됨.
- **주먹:** 주먹 풀기 순서(엄지 마디 → 손가락 → 엄지)는 손 펴기·휴식으로 갈 때만 씀. 검지 펴기·세손가락 등으로 바로 넘어가거나, 풀던 중 다른 동작이 오면 순서를 버림 → 엄지 뿌리가 손가락 위에 있는 채로 검지가 펴짐 (11-07 '엄지·검지 부딪힘' 과 같은 상황).

## 고친 것 (옵션, `emg_bridge_guarded` 기본은 끔 = 이전과 같음)
- `--tripod-switch-s 0.3`: 세손가락 중 다른 동작이 확정되면 머묾 없이 0.3 s 로 빨리 풀고 바로 넘어감 (휴식·손 펴기 쪽 풀기는 그대로).
- `--fist-unwind-any`: 주먹에서 어떤 동작으로 넘어가든, 풀던 중 끊기든 주먹 풀기 순서를 거침.
- 앱(`pc_tools/app/server.py`)은 의수 실행에 두 옵션을 붙임. 끄려면 환경 변수 `VASH_HAND_SWITCH=0`.

## 확인 (모의 계산, 모터 없음 — `docs/sim_interrupt_1112.py`)
- 끈 상태 = 이전과 같음: 무작위 메시지 48000 판단 다름 0, `--poses` 8 가지 명령 다름 0, 장면 결과 같음.
- 켠 상태 (새 동작이 손에 나오기까지 / 95 % 도착):

  | 장면 | 이전 | 켬 |
  |---|---|---|
  | 세손가락 → 주먹 | 0.78 s / 1.60 s | 0.22 s / 1.04 s |
  | 세손가락 → 손 펴기 | 0.58 / 1.32 | 0.22 / 0.96 |
  | 세손가락 쥐는 중 → 가위 | 0.38 / 1.00 | 0.02 / 0.66 |
  | 세손가락 → 잠깐 휴식 → 주먹 | 0.58 / 1.40 | 0.14 / 0.96 |
  | 주먹 → 잠깐 휴식(풀던 중) → 세손가락 | 목표 한 번에 73° 바뀜 | 16° |
  | 주먹 → 검지 펴기 | 검지 절반 펴질 때 엄지 뿌리 28° (손가락 위 그대로) | 엄지 뿌리 −6° (비킨 뒤 검지 폄), 도착 0.44 → 0.82 s |

- 대가: 주먹에서 다른 동작으로 넘어갈 때 엄지가 먼저 비키느라 0.3–0.4 s 늦어짐.
- 실제 손 확인 전.

## 연속·끼어듦 데모 (11-12 추가)
- `emg_bridge_guarded --demo --demo-seq default` : 휴식 → 주먹 → 검지(바로) → 휴식 → 세손가락 → 주먹(바로) → 휴식 → 세손가락 쥐는 중 → 가위 → 휴식 → 주먹 → 잠깐 휴식 0.25 s → 세손가락 → 휴식 → 세손가락 → 손 펴기 → 휴식 (한 바퀴 약 24 s, 각 동작 0.15 s 뒤 확정). 직접 순서: `--demo-seq "fist:1.5,index_ext:1.5,rest:1"`
- 모의 계산 그림 `docs/동작끼어듦_1112.png` (회색 이전, 빨강 고친 뒤)
  - 세손가락 → 주먹: 이전은 검지·중지를 다 폈다(0°) 다시 쥠, 고친 뒤는 77→98° 로 바로 쥠 (주먹 도착 약 0.7 s 빠름)
  - 세손가락 쥐는 중 → 가위: 이전은 검지·중지가 한 번 튐, 고친 뒤는 매끄러움
  - 주먹 → 검지: 고친 뒤는 엄지 뿌리가 −25° 까지 바깥으로 비켰다 돌아옴 (엄지 움직임이 더 큼)
