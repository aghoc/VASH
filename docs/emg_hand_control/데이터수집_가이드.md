## 0. 역할 나누기

| 정현 (실험실) | Claude (분석) |
|---|---|
| 보드 점검, 전극 붙이기, 녹화 | 녹화 품질 검사 (포화·누락·채널별 잡음·60 Hz) |
| 파일을 `C:\ads_bringup\pc_tools\data\` 에 저장 | 분류기 학습, R2·R3 재착용 시험, LDA/SVM 비교 |
| 아래 기록표 채우기 (한 줄이면 충분) | 서보 제어 단계 평가·튜닝 (`evalctrl`), 결과 보고서 |
| "S01 끝났어" 라고 알려 주기 | 배치·녹화 방법 개선안 → 다음 세션 반영 → 서보 코드 |

파일은 폴더에서 바로 읽으므로 따로 보낼 필요 없습니다. 이상한 점이 있었으면 메모만 남겨 주세요.

## 1. 준비물

- 보드 + ESP32 (점퍼), USB 케이블, **노트북 충전기 뽑기** (배터리로만)
- 3D 블록 v5 × 8 + 뚜껑 8 + 밴드 25 mm, 스냅 전극 16개 (바깥지름 19 mm 이하) + BIAS 전극 1개
- 줄자, 피부용 펜, 알코올 솜, 타이머 필요 없음 (프로그램이 지시)
- 메모용 기록표 (6절)

**안전**: 몸에 전극이 붙은 동안 노트북은 반드시 배터리 상태. 충전기를 꽂으면 60 Hz 잡음이 커지는 것뿐 아니라 몸이 콘센트 전원과 이어집니다. 피부가 따갑거나 붉어지면 바로 중단.

## 2. 자세 (매번 같게)

- 의자에 앉아 **팔꿈치 90°**, 아래팔은 책상 위, **엄지가 위를 향하는 중립 자세** (손바닥이 몸 쪽)
- 손목은 책상 끝 밖으로 나와 손가락이 자유롭게 움직이도록
- 전선 묶음은 책상에 테이프로 고정 (선이 흔들리면 움직임 잡음)
- 휴대폰·충전기·모니터 전원선에서 30 cm 이상 떨어지기

## 3. 붙이기 (그림 순서 ①~⑦)

1. 팔 길이 L 측정: 팔꿈치 뾰족한 뼈(주두) → 손목 새끼 쪽 뼈(척골 경상돌기)
2. 0.4 × L 지점에 펜으로 둘레 선, 그 지점 둘레도 측정
3. 척골 능선(팔꿈치에서 손목 새끼 쪽으로 만져지는 뼈 줄) 표시
4. 알코올 솜으로 닦고 완전히 마를 때까지 기다림 (1분)
5. 전극을 블록에 끼우고 뚜껑을 닫은 뒤 밴드에 8개를 순서대로 꿰기
6. CH1 블록을 능선 바로 옆 손등 쪽, **P(빨강) 각인이 팔꿈치 쪽**. 손등 → 엄지 쪽 → 손바닥 순서로 CH2…CH8. 능선 위는 비움
7. 블록 중심선이 펜 선에 오도록 밴드를 감기 — 손가락 하나가 들어갈 정도로
8. BIAS 전극을 팔꿈치 바깥 뼈(외측상과)에

L 이 25 cm 보다 짧으면 블록 손목 쪽 끝이 50 % 선을 넘을 수 있습니다. 비절단 측정에는 문제없지만 L 값을 꼭 기록해 주세요.

## 4. 녹화 전 점검 (5분)

```
cd C:\ads_bringup\pc_tools
python ads_monitor.py selftest --port COM6        (또는 시리얼 모니터에서 T)
```

| 확인 | 기준 | 안 맞으면 |
|---|---|---|
| T 결과 | 16/16 PASS (T12 는 전극이 붙어 있으면 전부 O) | 실패 항목을 그대로 알려 주기 |
| `D` 전극 검사 | 16개 모두 연결, \|P−N\| < 150 mV | 그 블록의 전극 교체·재부착 |
| 실시간 파형 | 아래 명령, 30초 휴식 | |

```
python ads_monitor.py live --port COM6 --ch 1-8
```

- 휴식: 모든 채널이 납작하고 60 Hz 굵은 띠가 없어야 함
- 엄지·검지·중지를 하나씩 구부려 보기: 손등 CH1–CH4, 손바닥 CH6–CH8 중 어딘가가 커져야 함
- 한 채널만 계속 크면(휴식인데) 그 블록 전극 접촉 확인

## 5. 녹화 순서 (세션 1회 ≈ 25분)

| 단계 | 명령 (파일명만 바꿔서) | 내용 |
|---|---|---|
| R1 학습 | `python finger_test.py record --port COM6 --ch 1-8 --side band --out data\20261017_S01_R1.csv` | 약 95초 |
| R2 같은 착용 | 같은 명령, `_R2.csv` | 쉬지 않고 바로 |
| 밴드 풀었다 다시 착용 | 3절 6~7번, 4절 점검 | 펜 선에 다시 맞춤 |
| R3 재착용 | 같은 명령, `_R3.csv` | |
| (선택) R4 팔 든 자세 | 같은 명령, `_R4.csv` | 팔꿈치 90° 그대로 책상에서 팔을 5 cm 들고 |

**동작 요령 (가장 중요)**

- 화면에 손가락 이름이 뜨면 그 손가락을 **손바닥 쪽으로 구부려 3초 유지**, "휴식"이 뜨면 힘 빼기
- 엄지: 엄지 끝을 새끼손가락 뿌리 쪽으로 접기 / 검지·중지: 손가락 끝을 손바닥으로 말기
- 힘은 **최대의 30~50 %** (편하게 계속 유지할 수 있는 정도) — 세션마다 같게
- 다른 손가락은 힘을 빼되 일부러 펴지 않기
- 휴식 때 주먹을 쥐거나 손을 펴서 버티지 않기 (B1 이 이 때문에 무효였음)
- 틀렸으면 멈추지 말고 끝까지 진행하고 메모. 다시 하려면 `_R1b` 로 새 파일

**세션 계획**: S01 (오늘) → S02 (다른 날, 같은 방법) → S03. 날이 다른 세션이 최소 2개 있어야 "다음 날에도 쓸 수 있는지"를 평가할 수 있습니다.

## 7. Claude 가 녹화마다 하는 분석

| 순서 | 내용 | 명령/산출물 |
|---|---|---|
| 1 | 품질: 누락 프레임, 포화 채널, 채널별 휴식 잡음, 60 Hz·고조파 비율 | `finger_test.py analyze` |
| 2 | 손가락 × 채널 반응표 (어느 블록이 어느 손가락을 잡는지) | 같은 분석 PNG |
| 3 | R1 교차검증, R1 모델 → R2·R3 적용 정확도 | `train`, `eval` |
| 4 | 서보 제어 단계: 휴식 오작동·맞는 손가락·떨림·지연, 문턱값·평활·전환 확인 시간 튜닝 (R1·R2 로 맞추고 R3 로 검증) | `evalctrl --plot` |
| 5 | LDA vs SVM, 채널 줄였을 때 (예: 6채널) 성능 | `compare`, `--mask` |
| 6 | 날짜가 다른 세션끼리 교차 시험 (S01 모델 → S02) | `eval` |
| 7 | 보고서 + 다음 세션 개선안 (블록 위치 이동, 힘 크기, 반복 횟수) | `data\분석_S01.md` |

판정 목표 (측정 기준 v1): 휴식 잡음 중앙값 ≤ 8 µV, R1 교차검증 ≥ 85 %, R2 ≥ 80 %, 서보 제어 휴식 오작동 ≤ 5 %, 맞는 손가락 ≥ 80 %. 넘으면 서보 제어 코드로 넘어갑니다.

## 8. 문제가 생기면

| 증상 | 먼저 볼 것 |
|---|---|
| T2 ID 0xFF | 칩 39·43번 다리 접촉 (이번 보드에서 실제 원인) |
| 잡음 큼, 온도 이상, T12 전부 O | 노트북 충전기 분리, 전극선 정리 |
| 한 채널만 휴식에도 큼 | 그 블록 전극 재부착·교체, `D` 로 \|P−N\| 확인 |
| 녹화 중 "누락" 증가 | USB 허브 대신 본체 포트, 다른 프로그램이 COM6 사용 중인지 |
| 손가락을 움직여도 반응 없음 | 블록이 들떠 있음 → 밴드 조이기, 전극 젤 마름 → 교체 |
