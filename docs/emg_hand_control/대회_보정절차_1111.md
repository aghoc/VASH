# 대회·시연 보정 절차 (11-11 기준)

## 한 줄 요약
밴드를 찬 상태 그대로 **앱 정밀 보정 한 번 → 메인 SVM 자동 선택 → 바로 사용**. 거치대를 달고 쓸 거면 **단 채로**, `거치대 착용` 체크.

## 순서
1. 밴드 착용. 피부·밴드에 표시해 둔 자리에 맞춰 찬다 (CH1 = 척골 능선 옆 손등 쪽, BIAS = 외측상과).
2. (시연 조건 그대로) 거치대를 달 거면 지금 단다. 달았으면 정밀 보정 칸의 `거치대 착용` 체크.
3. **[위치 확인]** (약 30 초: 손 펴기·주먹·가위·검지·엄지 한 번씩)
   - 마지막 정밀 보정 때 위치와 비교해서 '위치 좋음' 또는 '밴드를 엄지 쪽/새끼(척골) 쪽으로 약 1 칸 돌리세요' 와 접촉 나쁜 채널을 알려 줌
   - '좋음' 이 나올 때까지 돌리고 다시 확인 (거치대 착용이면 CH5–7 은 빼고 비교)
   - 돌림이 아닌데 낮으면 팔꿈치·손목 쪽으로 밀렸거나 접촉 문제 → 표시한 자리에 다시
4. 앱 → 정밀 보정
   - 거치대를 달았으면 `거치대 착용` 체크 → CH5–7 잡음·약한 신호·위치 경고는 묻지 않고 넘어감
   - 다른 채널(CH1–4, CH8) 경고가 뜨면 그 전극만 눌러 붙이고 [다시 확인]
   - 보정 녹화 2 회 → 전환 녹화 → 마지막 단계 약 40 초
5. 끝나면 **VASH SVM (메인)** 이 자동 선택됨
6. **[분류 확인]** (약 40 초: 7 동작 한 번씩) → 동작별 맞음·틀림, 도중에 잠깐 다른 동작이 끼었는지
   - 모두 맞음 → 사용. 1 개 틀림 → 그 동작을 다시 해 보고, 계속 틀리면 정밀 보정 다시. 여러 개 틀림 → 위치 확인부터 다시
7. 근전도 켜기 → 휴식 5 초 기다림 → 사용
8. 화면에 '기본 모델 강화 중' 이 보여도 그냥 쓰면 됨 (다음 보정 때 쓰이는 재료를 만드는 중)

## 하지 말 것
- 보정한 뒤 밴드를 풀거나 크게 돌리기 → 다시 보정해야 함
- 어제 모델을 그대로 쓰기 (밴드를 다시 차면 맞지 않음)

- 판단 설정(확정 최소 시간, 바꿀 때 유지, SVM 온도)을 바꿔도 중간 오판은 125→130 정도만 줄고 확정만 늦어짐 → 그대로

  - 정밀 보정 뒤에는 LDA 가 기본 선택이었음
- 거치대를 달면 CH5–7 이 매번 눌림 (11-09·11-10 모두 CH6·CH7 신호 대 잡음 1–2 dB). 그래도 보정 후 재생 정답은 SVM 41/42·48/48·49/49

## 위치 확인 검증 (11-11, 지난 녹화)
- 같은 착용끼리: 0.95 '좋음'
- 채널을 일부러 ±1, +2 칸 밀어 만든 가짜 녹화: '엄지 쪽 약 1 칸', '새끼 쪽 약 1 칸', '엄지 쪽 약 2 칸' → 돌려 맞추면 0.95
- 다른 날: 같은 자리(①)로 찬 날 0.92 '좋음', 다른 자리(②) 0.81 '조금 어긋남'
- 실제로 밴드를 돌려서 방향이 맞는지는 아직 확인 안 함 (칸 = 전극 간격 기준 대략값)
