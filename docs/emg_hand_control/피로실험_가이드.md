# 피로 실험 가이드 (F1, v2 — 2026-10-27 수정)

목적: 같은 착용 상태에서 **피로 전 → 피로가 쌓여 가는 단계(T1·T2·T3) → 회복 후** 동작별 분류 정확도를 비교하고,
라벨 없이 쓰는 보정이 피로 후 정확도를 얼마나 되살리는지 확인. 결과는 `fatigue_experiment.py` 한 번으로 나옴.

## v1 에서 바뀐 점과 이유

| 바뀐 점 | 이유 |
|---|---|
| 피로 유발을 한 번에 몰아서 하지 않고 **3단계로 나눔** (유발 → 짧은 시험 → 유발 → 시험 …) | 피로 정도가 다른 시점이 여러 개 있어야 φ(라벨 없음)와 실제 피로의 상관, 피로 방향 모델(G2)을 검증할 수 있음. 한 시점뿐이면 계산 자체가 안 됨 |
| 시험 녹화를 **반복 3회**로 짧게 | 시험하는 동안 근육이 회복되면 피로 효과가 희석됨 |
| (권장) **주방 저울로 힘 고정** | 피로하면 같은 힘을 주려 해도 힘이 줄어듦. 힘이 같아야 "피로 때문"이라고 말할 수 있고, 세기 보정 γ 도 맞출 수 있음 |
| 피로 전·연습 녹화 앞의 **5 초 휴식은 꼭 가만히** | 휴식 재보정과 휴식 기준 주파수에 그대로 쓰임 |

## 규칙

- **밴드를 처음부터 끝까지 벗지 않는다**
- 노트북 충전기 분리, 같은 자세 (팔꿈치 90°, 엄지 위)
- 손가락 동작은 매번 같은 힘 (최대의 30~50 %, 저울을 쓰면 손가락 끝으로 **약 300 g**을 눌러 유지)
- 피로 유발 주먹은 최대의 50~70 %. 마지막 10~20 초가 버거울 정도
- 아프거나 쥐가 나면 즉시 중단 (그때까지 녹화로도 분석 가능)

## 순서와 명령 (pc_tools 폴더, .venv 켠 상태) — 약 30분

| 단계 | 시간 | 명령 |
|---|---|---|
| 0 | 5분 | 착용 → 안정 대기 → `python ads_monitor.py selftest --port COM6` (16/16) |
| 1 | 1분 | 연습 `python finger_test.py record --port COM6 --ch 1-8 --side band --reps 2 --out data\F1_practice.csv` |
| 2 | 2분 | **피로 전** `python finger_test.py record --port COM6 --ch 1-8 --side band --out data\F1_pre.csv` |
| 3 | 2.5분 | 피로 유발 1 `python finger_test.py record --port COM6 --ch 1-8 --side band --gestures "주먹 (최대의 50~70 %)" --reps 2 --hold 60 --rest 10 --out data\F1_sus1.csv` |
| 4 | 1분 | **시험 T1** (바로) `python finger_test.py record --port COM6 --ch 1-8 --side band --reps 3 --out data\F1_T1.csv` |
| 5 | 2.5분 | 피로 유발 2 (3 과 같은 명령) `--out data\F1_sus2.csv` |
| 6 | 1분 | **시험 T2** (4 와 같은 명령) `--out data\F1_T2.csv` |
| 7 | 2.5분 | 피로 유발 3 `--out data\F1_sus3.csv` |
| 8 | 1분 | **시험 T3** `--out data\F1_T3.csv` |
| 9 | 10분 | 휴식 (밴드 그대로, 팔 편하게) |
| 10 | 2분 | **회복 후** `python finger_test.py record --port COM6 --ch 1-8 --side band --out data\F1_recover.csv` |

- 3·5·7: 화면에 "주먹 (최대의 50~70 %)" 이 60 초 떠 있는 동안 같은 힘으로 쥐고, "휴식" 10 초에 풀기를 2 번
- 4·6·8 은 유발이 끝나면 **쉬지 말고 바로** 시작 (명령을 미리 입력해 두고 ↑ 키로 불러오기)
- 단계마다 파일명만 바꾸면 됨. 실수하면 멈추지 말고 끝까지 하고 메모

## 분석 (녹화 후, 또는 Claude 에게 "F1 끝났어")

```
python fatigue_experiment.py --pre data\F1_pre.csv --post data\F1_T1.csv data\F1_T2.csv data\F1_T3.csv --recover data\F1_recover.csv --out data\fig_fatigue_accuracy.png
python fatigue_scope.py data\F1_sus1.csv data\F1_sus2.csv data\F1_sus3.csv --out data\fatigue_scope_F1.png
```

출력
- [1] 동작별 정확도: 피로 전(반복 교차) / 피로 후 (방법 7가지) / 회복 후
- [1b] 피로 단계 T1·T2·T3 별 정확도와 피로 지수 φ
- [G0] 피로로 5 %p 이상 떨어졌는지 · [G1] 같은 동작 주파수 비율(휴식은 1 근처여야) · [φ] 라벨 없는 φ 와 실제의 상관 · [G2] 피로 방향 모델 설명 비율
- 그림 a 동작별 정확도 (피로 전 → T1 → T2 → T3 → 회복), b 주파수 비율, c 보정 방법별 정확도
