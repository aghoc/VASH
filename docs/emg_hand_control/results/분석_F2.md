## 1. 집기 ↔ 세손가락 구분: 됨 (핵심 결과)

| 녹화 | 4클래스 | 집기 재현율 | 세손가락 재현율 |
|---|---|---|---|
| G1 (중지 지시 없음, 10-24) | 5종 73.7 % | — | **31.6 %** (대부분 집기로) |
| G2 | 98.8 % | 97.6 % | 96.4 % |
| F2_B1 | 98.6 % | 97.6 % | 96.7 % |
| F2_B2 | 96.8 % | 87.5 % | 95.7 % |
| F2_recover (피로 뒤 10분) | 98.1 % | 96.7 % | 95.2 % |

- 집기에서 중지를 펴 들면 CH4 가 크게 커짐 (집기 ~90 µV vs 세손가락 ~52 µV), 세손가락은 CH5·CH6 이 더 큼 → 패턴이 갈림
- 네 번 녹화 모두 재현됨 (같은 착용). 단 G1 은 약/강 섞기·5종이라 조건이 완전히 같지는 않음
- **약점: 시작 순간 0.25 s 판단으로는 집기 1/5~2/6** — 처음엔 세손가락으로 읽힘 (손을 모은 뒤 중지를 펴는 순서라 펴는 신호가 늦게 나옴). 유지 구간 창 판단은 95~98 %. → 쥐기 종류는 0.5 s 이상 보고 결정해야 함

## 2. 피로: F1 보다 약하게 생김

- 60 초 유지 중 MDF −4.2 % (F1 −6.1 %), p 0.018
- 같은 동작 MDF 비율 0.98~0.99 (F1 0.90~0.94) — 시험 동작 쪽에는 피로가 거의 안 남음
- **휴식 MDF 비율 0.81 → 대조 조건 실패**: B2·회복 녹화의 휴식 RMS 가 B1 보다 높음 (CH3~5 약 12 µV vs 2~5). 피로 외 변화(근육이 덜 풀림·전극 상태)가 섞임
- 가능한 이유: 같은 날 F1 을 이미 해서 근육이 단련/소진된 상태, 피로 유발이 주먹인데 집기는 다른 근육(CH4) 위주

## 4. 포스터에 쓸 것

- **쓸 수 있음 (강함)**: 중지 펴기/굽힘으로 집기 ↔ 세손가락 구분 31.6 % → 96 % 이상, 4번 녹화 재현
- **쓸 수 있음 (F1 과 함께)**: 가장 피로한 구간에서 쥐기 하나(세손가락)가 82 % 로 떨어지고 정답 보정으로 회복 — F1 엄지와 같은 양상
- **쓰면 안 됨**: "F2 에서도 비전 보정이 전체적으로 오동작을 크게 줄였다" (T3 에서 반대, 전체 −12 %)
