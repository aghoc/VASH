# 측정 기준 v1 — 둘레형 8채널 밴드 (2026-10-11 시작)

이 문서 이후의 측정은 모두 이 기준으로 한다. 이전 데이터(A1, B1, B2)는 배치가 달라 **비교 참고용**으로만 쓴다.

## 1. 고정 조건

| 항목 | 기준 v1 |
|---|---|
| 하드웨어 | ADS1299 보드 + ESP32-S3 (COM6), 펌웨어 v1.10, 2000 SPS, 8채널 전부 사용(`--ch 1-8`) |
| 전극 | 3D 출력 블록 v3 × 8 + 밴드(폭 20, 두께 2 mm) + 스냅 케이블 |
| P–N 간격 | **20 mm** (블록 `PITCH = 20`, 외형 19.7 × 60.0 × 14.3 mm) |
| 전극 크기 | 스냅 전극 **바깥지름 19 mm 이하** (20 mm 간격이라 더 크면 P·N 이 겹침 → 폼을 잘라 쓰거나 소형 전극) |
| 위치 | 팔 길이 L(주두 → 척골 경상돌기)의 **40% 를 블록 중심선**으로. P = 팔꿈치 쪽(38–40%), N = 손목 쪽(40–42%) → 34–46% 띠 안 |
| BIAS | 외측상과(팔꿈치 바깥 뼈) 위 별도 스냅 전극 1개 |
| 동작 | 4클래스: 휴식 · 엄지 · 검지 · 중지 **구부리기**(`--side band`) |
| 녹화 | 반복 5, 힘주기 3 s, 휴식 3 s, 시작 휴식 5 s → 약 95 s |
| 분류기 | LDA(수축 0.05), 200 ms 창 / 50 ms 판단, 특징 32개, 다수결 3 |
| 필터 | 20–450 Hz + 60/120/180 Hz 노치 + 분석 시 240/300/360/420 Hz 노치 |

## 2. 블록 → 채널 배치 (왼팔, 손등 쪽에서 볼 때. 오른팔은 좌우 반전)

척골 능선(뼈가 만져지는 줄)을 기준점으로, 그 바로 옆에서 시작해 손등 → 요측 → 손바닥 → 다시 척골 능선 순서로 감는다. **척골 능선 위는 비워 둔다.**

| CH | 둘레 위치 | 주 대상 |
|---|---|---|
| 1 | 손등 척측 (능선 바로 옆) | ECU · 깊은 EPL (엄지 펴기·손목) |
| 2 | 손등 척측-가운데 | EDC 약지/새끼 · EPL |
| 3 | 손등 가운데 | EDC 중지 |
| 4 | 손등 요측-가운데 | EDC/ECRB · 깊은 APL |
| 5 | 요측 가장자리 | APL/EPB · ECRL |
| 6 | 손바닥 요측 | FCR · 깊은 FPL · FDS 검지 |
| 7 | 손바닥 가운데 | FDS |
| 8 | 손바닥 척측 (능선 반대편 옆) | FDP · FCU |

둘레 간격 = 둘레 / 8 (둘레 25 cm 면 약 3.1 cm, 블록 사이 틈 약 11 mm).

## 3. 매 세션 순서

1. **팔 치수 기록**: L(cm), 40% 지점 둘레(cm). 40% 선과 척골 능선을 펜으로 표시.
2. **피부 준비**: 알코올 솜으로 닦고 마를 때까지 기다림.
3. **착용**: CH1 블록을 척골 능선 바로 옆 손등 쪽에 두고 나머지를 순서대로. 블록 P/N 각인이 팔꿈치/손목 방향과 맞는지 확인. 밴드는 손가락 하나 들어갈 정도로.
4. **점검**
   - 펌웨어 `T` → 전부 PASS
   - `D` → 8채널 모두 연결, |P−N| < 150 mV (넘으면 그 블록 전극 교체)
   - `python ads_monitor.py live --port COM6 --ch 1-8` 로 30 s 휴식 확인: 60 Hz 험 없음, 손가락 하나씩 움직여 반응 확인
5. **녹화 R1 (학습용)**
   `python finger_test.py record --port COM6 --ch 1-8 --side band --out 20261011_S01_R1.csv`
6. **녹화 R2 (같은 착용, 시험용)** — 쉬지 않고 바로 같은 명령, `_R2.csv`
7. **벗었다 다시 착용** → 4번 점검 → **녹화 R3** `_R3.csv`
8. **분석**
   ```
   python finger_test.py analyze 20261011_S01_R1.csv
   python emg_classifier.py train 20261011_S01_R1.csv --out S01_R1.npz
   python emg_classifier.py eval --model S01_R1.npz 20261011_S01_R2.csv 20261011_S01_R3.csv
   python emg_classifier.py compare 20261011_S01_R1.csv
   python emg_classifier.py run --model S01_R1.npz --replay 20261011_S01_R2.csv
   ```
9. **기록표(아래)에 결과 기입**.

파일 이름: `날짜_S세션번호_R녹화번호.csv` (예 `20261011_S01_R1.csv`). 녹화를 다시 하면 `R1b` 처럼 붙이고 이전 파일은 지우지 않는다.

## 4. 판정 기준 (v1 잠정)

| 지표 | 명령 | 목표 | 의미 |
|---|---|---|---|
| 점검 | `T`, `D` | 전부 PASS / 연결 | 미달이면 녹화하지 않음 |
| 휴식 잡음 | `analyze` 휴식µV | 중앙값 ≤ 8 µV (도구 경고 기준) | 넘으면 힘 빼기·접촉 재확인 |
| 같은 녹화 교차검증 | `train` | ≥ 85% (B2 86.5% 수준) | 배치 자체의 분리 능력 |
| 같은 착용 다른 녹화 | `eval` R2 | ≥ 80% | 실사용 기대치 |
| 재착용, 재학습 없음 | `eval` R3 | 기록만 | 재보정 필요성 판단 (참고: 배치가 다른 B2 모델을 A1 에 적용하면 18%) |
| LDA vs SVM | `compare` | 기록만 | 데이터 쌓이면 분류기 재선택 근거 |
| 처리 지연 | `run --replay` | 중앙값 < 10 ms | 실시간 여유 |
