# 동작 흐름 일반화 (11-10) — 집기·가위·검지 펴기·엄지 펴기

세손가락에 넣은 순서 있는 움직임(엄지 동선 표, 준비 지점에서 머묾, 풀 때 거꾸로)을 다른 동작에도 같은 방식으로 넣었다.
**11-11 정현 결정으로 다시 기본 끔 (11-10 저녁에 잠깐 기본 켰다가 롤백). 주먹·세손가락 동선은 별개라 그대로.** **기본은 꺼져 있다.** `--flow` 를 주지 않으면 이전과 똑같이 움직인다 (아래 확인 참고).
시작 자세(대기)와 끝 자세(손으로 만든 최종값)는 그대로 두고, 그 사이의 순서·경로·속도만 바꿨다.
**모든 결과는 모의 계산(모터 없음, Composer+Smoother)이다. 실제 손에서는 아직 돌려 보지 않았다.**

## 1. 지금(흐름 끔) 움직임

동작 모드 자세(가위·검지 펴기·엄지 펴기)는 근전도 세기가 바로 1 근처로 올라서 **모든 관절이 같은 시각에 출발해 직선으로** 간다 (Smoother 는 관절을 동기화하고 시차는 30–90 ms 뿐이다). 기준점 경로(paths)는 c 가 천천히 오를 때만 효과가 있어서, 실제로는 순서가 거의 없다.

| 동작 | 엄지 끝 자세 | 지금 문제 (모의 계산) |
|---|---|---|
| 가위 | 약지·소지 위를 덮음 (CMC +52°) | 엄지 뿌리가 절반 넘어갈 때 약지는 **35 %** 만 굽음 → 덜 말린 약지 끝에 엄지가 걸릴 수 있음 |
| 검지 펴기 | 중지 위를 덮음 (CMC +53°) | 엄지 뿌리 절반 때 중지 60 %, 약지 30 % → 주먹 엄지와 같은 간섭 구조 |
| 엄지 펴기 | 밖으로 쭉 폄 (MCP −61°) | 엄지와 네 손가락이 동시에 (50 % 시각 0.22 s vs 0.20 s) → 말리는 검지가 엄지 끝을 스칠 수 있음 |
| 집기 | 마주봄 (CMC +23°) | 이미 준비 자세(approach 0.5)가 있어 엄지가 먼저 감, 검지는 바로 닫힘 (벌렸다 닫는 단계 없음) |
| 손 펴기 | — | 대기 → 손 펴기는 모두 펴는 쪽이라 서로 안 막음 → **바꾸지 않음** |
| 주먹·감싸 쥐기·세손가락 | — | 이미 흐름 있음 → **그대로** |

## 2. 흐름 표와 근거

근거
- 엄지는 쥘 때 MCP → IP 순서로 굽고, 펼 때 IP 가 먼저 펴진다 (Carpinella 2011, J NeuroEng Rehabil 8:19).
- 집기: 엄지는 거의 고정된 기준점처럼 먼저 자리를 잡고, 검지가 벌렸다가(최대 벌림) 닫으며 크기를 맞춘다 (Jeannerod 1984; Wing & Fraser 1983).
- 약지·소지는 중지와 묶여 함께 굽는다 (Häger-Ross & Schieber 2000).
- 엄지가 손가락 위를 덮는 동작(가위·검지 펴기)은 덮일 손가락이 먼저 말린 뒤에 덮는다. 이건 문헌이 아니라 **이 손의 간섭 기하**다 (주먹과 같은 이유, 11-07).

c = 쥐는 정도 0→1. 풀 때는 같은 표를 c 1→0 으로 거꾸로 간다.

| 동작 | 순서 (쥘 때) | 풀 때 |
|---|---|---|
| 가위 | ① 약지·소지 말림 (c 0.4 에 85 %) ② 엄지 끝 펴서 듦 (0.3) → 마디 편 채 뿌리만 넘어감 (0.55) → 뿌리 끝 자리·MCP (0.75) ③ 검지·중지 폄 (0.5–0.85) ④ V 벌림 (0.6–0.9) ⑤ 엄지 IP 눌러 덮음 (1.0) | V 모음 → 엄지 IP·MCP 폄 → 엄지 뿌리 빠짐 → 약지·소지 폄 |
| 검지 펴기 | ① 검지 폄 (c 0.35 에 끝) ② 중지 → 약지 → 소지 말림 ③ 엄지: 끝 듦 (0.45) → 뿌리 넘어감 (0.7) → MCP (0.85) → IP (1.0) | 엄지 IP → MCP → 뿌리 빠짐 → 세 손가락 폄 |
| 엄지 펴기 | ① 엄지 IP 먼저 폄 (0.15) → MCP·뿌리 (0.4) ② 다 비킨 뒤 네 손가락 말림 (0.4–1.0, 약지·소지 조금 늦게) | 손가락 먼저 폄 → 엄지 MCP·뿌리 → IP |
| 집기 | ① 엄지 뿌리가 마주보는 자리로, 동시에 검지는 손 펴기 값까지 벌림 (c 0.35) ② 그 지점에서 머묾 (0.15 s) ③ 검지가 엄지 쪽으로 닫힘 ④ 엄지 MCP (0.7) → IP (1.0) | 엄지 IP → MCP → 준비 지점(엄지 마주봄·검지 폄)에서 0.1 s 머묾 (물체 빠질 틈) → 대기 |

표는 `right-no-wrist\emg_grips.yaml` 의 `flow:` 항목에 있다 (thumb_path 는 thumb_paths 와, paths 는 paths 와 같은 형식).

## 3. 새 옵션 (emg_bridge_guarded.py, start_hand.py 로도 그대로 넘어감)

| 옵션 | 기본 | 권장 | 뜻 |
|---|---|---|---|
| `--flow` | (빈 값 = 끔) | `pinch,scissors,index_ext,thumb_ext` (`all` 도 됨) | 흐름 켤 자세 |
| `--flow-close-s` | 0.45 | 0.45 | 동작 모드 자세의 c 가 0→1 로 가는 최소 시간 (세기가 확 올라도 표 순서 유지) |
| `--flow-unwind` | 0.5 | 0.5 (빠르게 하려면 0.35) | 풀 때 표를 거꾸로 가는 시간. 0 = 바로 대기로 |
| `--flow-open-hold` | 0.15 | 0.15 | 집기: 검지 편 준비 지점에서 머묾 |
| `--flow-rel-hold` | 0.1 | 0.1 | 집기 풀 때 준비 지점에서 머묾 |

`--flow` 를 안 주면 나머지 네 옵션은 쓰이지 않는다.

앱
- 동작 수정 팝업 미리보기에 [세손가락][집기][가위][검지 펴기][엄지 펴기] 버튼과 '새 동작 흐름' 체크를 넣음. 체크하면 미리보기에만 `--flow pinch,scissors,index_ext,thumb_ext` (체크 끄고/켜고 비교 가능).
- 의수 실행에 쓰려면 앱을 켜기 전에 환경 변수 `VASH_HAND_FLOW=pinch,scissors,index_ext,thumb_ext`. 없으면 이전과 같다 (장력·캘리브레이션 버튼에는 안 붙음).
- 제슨: 이 상태로 넘겨도 기본은 꺼짐. 켜는 값은 위 권장값.

## 5. 모의 계산 결과 (`docs\sim_flow_1110.py`, 전체 출력 `docs\sim_flow_1110_결과.txt`)

대기 0.5 s → 확정 동작 (세기 최대) 2.5 s → 휴식. 확정 순간 = 0 s. 실제 모터 지연·마찰은 들어 있지 않다.

| 동작 | 끝 자세 차이 | 쥐기 95 % 도착 끔 → 켬 | 풀기 95 % 끔 → 켬 | 엄지 뿌리 절반 지날 때 덮일 손가락 진행 끔 → 켬 |
|---|---|---|---|---|
| 집기 | 0.00° | 0.82 → 0.80 s | 0.80 → 1.30 s | 검지 MCP 45 % → −3 % (엄지가 먼저, 검지는 벌어진 상태) |
| 가위 | 0.00° | 0.70 → 0.86 s | 0.70 → 1.04 s | 약지 35 % → 84 % |
| 검지 펴기 | 0.00° | 0.72 → 0.88 s | 0.70 → 0.98 s | 중지 60 % → 96 %, 약지 30 % → 84 % |
| 엄지 펴기 | 0.00° | 0.72 → 0.98 s | 0.70 → 0.84 s | (덮지 않음) 엄지 50 % 0.28 s, 검지 50 % 0.36 s (끔: 0.22 / 0.20) |

- 비전 집기 (손 펴기 → 준비 자세 → 주먹=집기): 엄지 목표 한 주기 최대 변화 23° → 4° (준비 자세에서 이어 감).
- 대가: 쥐기 0.16–0.26 s, 풀기 0.14–0.5 s 늦어짐. 동작끼리 바로 바꾸면 (가위 → 검지 펴기) 앞 동작을 거꾸로 푼 뒤 다음 동작으로 가서 약 0.5 s 더 걸림.
- 남은 한계: 주먹 → 가위처럼 흐름 없는 자세에서 바로 넘어오면 엄지 표가 대기 기준이라 엄지 목표가 크게 바뀜 (끔 63°, 켬 54°, 이전보다 나빠지지는 않음).

## 6. 실제 손에서 볼 순서 (정현이 실행)

1. 앱 동작 수정 팝업 → 미리보기 (체크 끄고 한 번, 켜고 한 번): [가위] [검지 펴기] [엄지 펴기] [집기]
   또는 터미널 B (orca_core):
   `uv run --frozen --no-dev python ../hand-config/right-no-wrist/emg_bridge_guarded.py --poses --only scissors --close-s 1.5 --hold 1.0 --flow scissors`
2. 볼 것
   - 가위: 약지·소지가 먼저 다 말리는지, 엄지가 그 위로 넘어갈 때 약지 끝에 안 걸리는지, V 가 마지막에 벌어지는지
   - 검지 펴기: 엄지가 중지 위로 넘어갈 때 중지가 거의 다 말려 있는지, 엄지 끝이 중지에 안 걸리는지
   - 엄지 펴기: 엄지 끝마디가 먼저 펴지고 엄지가 비킨 뒤 검지가 말리는지 (검지가 엄지 끝을 스치지 않는지)
   - 집기: 엄지가 먼저 마주보는 자리로 가고, 검지가 펴졌다가 잠깐 멈춘 뒤 닫히는지. 손끝이 정면으로 만나는지
   - 풀기: 모두 거꾸로 (엄지 IP 먼저)
3. 데모 한 동작씩: `start_hand.py --demo --demo-grip pinch --flow pinch` (가위·검지·엄지는 `--demo-grip 가위` 등)
4. 괜찮으면 실사용: 앱 켜기 전 `VASH_HAND_FLOW=pinch,scissors,index_ext,thumb_ext`, 또는 `start_hand.py ... --flow pinch,scissors,index_ext,thumb_ext`
5. 느리면 `--flow-close-s 0.3`, `--flow-unwind 0.35`. 엄지 표 값(0.30/0.55, 0.62/0.25 등)은 주먹 표를 그대로 쓴 추정값이라 걸리면 그 값을 고친다
