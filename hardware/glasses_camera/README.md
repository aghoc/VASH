# Glasses Camera

ELP IMX291(38×38 mm 보드)을 안경 다리 바깥쪽에 고정하는 포드입니다. 안경 다리에 구멍을 뚫어 M2 볼트 2개로 고정합니다.

| File | Description |
|---|---|
| `pod_front_*_v15.stl` | 포드 앞면 |
| `pod_rear_*_v15.stl` | 포드 뒷면과 꼬리 |
| `lens_shroud_*_v15.stl` | 렌즈 경통을 감싸는 튜브 |
| `drill_guide_*_v15.stl` | 안경 다리 구멍 가공용 가이드 |

`L`은 왼쪽, `R`은 오른쪽입니다. 왼쪽은 앞면이 막혀 있고 슈라우드도 닫혀 있습니다.
