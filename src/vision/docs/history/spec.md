# **2. 손가락 제어 배분**

엄지·검지·중지만 EMG로 직접 제어하고, 약지·소지는 중지 서보모터 각도에 비례해서 따라 움직인다. 지금 단계에서는 다섯 손가락 모두 서보를 그대로 유지하고 소프트웨어로만 비례 제어하며(초기 세팅), 서보 자체를 물리적으로 줄이는 건 경량화 단계로 미룬다.

## **해부학적 근거**

심지굴근(FDP)은 요측 다발(검지 전담, 상대적으로 독립적)과 척측 다발(중지·약지·소지가 하나의 근복을 공유, 서로 얽혀 있음)로 나뉜다. 건강한 사람도 약지만 선택적으로 굽히는 것이 불가능하다는 것이 실측 연구(Kilbreath & Gandevia, 1994)로 확인된 바 있다. 엄지(장무지굴근, 완전 독립)와 검지(FDP 요측 다발, 상대적 독립)만 EMG로 분리해내는 것이 해부학적으로 타당하다.

# **3. AR/Jetson 비전 파이프라인**

## **3-1. 타겟 선정 — Center Bias**

아이트래킹을 사용하지 않는다. 사물 인식이 찾아낸 여러 바운딩박스 중, 카메라 화면 중심과의 유클리드 거리가 가장 가까운 박스를 타겟으로 선정한다. 고개를 돌려 물체를 화면 중앙에 두는 행동 자체가 사용자의 관심/의도 신호가 된다.

## **3-2. 안정화 — 디바운싱 + 히스테리시스**

* N-프레임 윈도우: 최근 n개 프레임을 큐에 저장, 중심에 가장 가까운 객체가 n번 연속(또는 n프레임 중 80% 이상) 동일할 때만 최종 타겟으로 확정
* 히스테리시스: 이미 락된 타겟에 거리 가산점을 부여해, 다른 객체가 더 가까워져도 그 격차가 임계치(x%)를 넘어야만 타겟이 전환됨
## **3-3. 모델 및 연산 성능 (2026-08-17 개정)**

비전 모델은 `YOLO26s`, 배포 precision은 `TensorRT FP16`으로 확정한다. 기본 one-to-one
end-to-end/NMS-free head를 사용하며, 학습은 FP32로 수행한다. Jetson Orin Nano Super 공식
참고치에서 YOLO26s FP16 추론은 7.17 ms/image(전·후처리 제외)다. 실제 합격 판정은 공식 수치가
아니라 프로젝트의 15-class validation 정확도, 전체 vision pipeline p95 latency 50 ms 이하,
FPS, peak memory와 장시간 안정성을 함께 측정해 결정한다. 이전 YOLOv8n INT8 수치는 과거
설계 참고값이며 현재 배포 기준이나 완료 근거로 사용하지 않는다.

# **4. ESP32 ↔ Jetson 통신 인터페이스**

전원 케이블이 이미 유선으로 연결되어 있으므로 데이터도 무선(WiFi/BLE) 대신 유선 UART로 전송한다. 배터리 단계로 넘어갈 때 무선 전환을 재검토한다.

| **필드** | **용도** |
| --- | --- |
| 그립 후보 ID | 비전이 추천하는 그립/타겟 형태 |
| 신뢰도(0~100) | 안전원칙 2(신뢰도 게이팅)에 직접 사용 |
| 목표 개구량 | 손가락이 벌어져야 할 정도(연속값) |
| 시퀀스 번호 | ESP32가 데이터 최신 여부 판단 |
| 체크섬 | 통신 오류 감지 |

ESP32의 EMG 제어 루프(1~5ms 주기)는 Jetson의 느린 비전 추론을 기다리지 않고, 매 사이클마다 가장 최근에 받은 Jetson 데이터만 참고한다(producer-consumer 구조). 일정 시간(예: 200~300ms) 이상 새 데이터가 없으면 자동으로 순수 EMG 제어로 폴백한다.

# **5. 안전 설계 10원칙**

1. 계층적 권한 구조 — 비전 AI는 제안만, EMG가 실행 여부의 최종 권한
2. 신뢰도 게이팅 — 비전 신뢰도가 임계치 이하면 현재 상태 유지
3. 변화율 제한 — 관절 변화 속도 상한으로 즉시 스냅 방지
4. 접촉 후 그립 락 — 접촉 감지 시 비전 기반 조정 중단, 촉각/전류가 우선권
5. 놓기 신호 최우선 + 세이프 스톱 — 급격한 EMG 신호 시 전체 정지 후 폴백
6. Hold Last Known Good State — 지연/드롭 시 마지막 확정 상태 유지
7. 하드웨어 힘 제한 — 소프트웨어와 독립된 물리적 상한(최후 안전망)
8. 신호 열화 시 안전 강등 — 신호질 저하 시 단순 개폐 모드로 자동 전환
9. 사용자 인지 피드백 — 현재 제어 모드를 항상 표시
10. Center Bias 기반 타겟 확정 — 중심 최근접 + N프레임 안정화(3장 참조)
# **6. 그립 힘 결정 전략**

EMG는 사용자의 의도(얼마나 세게 쥐려 하는가)만 반영할 뿐, 실제 물체와의 상호작용 상태(미끄러짐 여부)는 담고 있지 않은 정보다. 이는 알고리즘으로 보완할 수 없는 정보 자체의 부재이며, 절단 환자들이 촉각 피드백 없이 과대/과소 그립을 반복하는 이유와 같은 근본 원인이다.

| **단계** | **방법** | **비고** |
| --- | --- | --- |
| Phase A (현재) | Dynamixel XC330의 Present Current(주소 126) 값을 안전 상한선으로 사용. 접촉도 전류 급상승+위치 정체로 동시에 감지(추가 부품 불필요) | Operating Mode 5(Current-based Position Control)가 그리퍼용으로 공식 권장됨 |
| Phase B (경량화 단계) | 엄지·검지·중지 손끝에만 경량 FSR 촉각센서 추가, 진짜 슬립 감지 폐루프 구현 | 참고 사례: JHU Reflex(저비용 텍스타일 FSR), Southampton Hand, 2026 Frontiers 무보정 3축 촉각 슬립제어 |

*주의: XC330 시리즈는 모터 위상 전류가 아닌 입력 전원단 전류를 측정하므로, 정밀한 슬립 감지보다는 거친 안전 상한선 용도에 적합하다.*

# **7. 최종 그립 인터랙션 플로우**

| **단계** | **내용** | **주도** |
| --- | --- | --- |
| ① 타겟 선정 | Center Bias + 디바운싱/히스테리시스로 안정화 | 비전 |
| ② 개구량 제안 | 물체 크기 기반으로 Jetson이 계산, ESP32로 전송 | 비전 |
| ③ 접근 시작 | EMG가 의도를 확인해야 실제 접근 시작, 변화율 제한 적용 | 비전+EMG |
| ④ 접촉 감지 | Present Current 급상승 + 위치 정체를 동시에 확인(무센서) | 서보 내부 신호 |
| ⑤ 전류 기반 힘 제어 | Current Limit을 하드 상한으로, EMG 세기가 그 안에서 Goal Current 조절 | EMG |
| ⑥ 놓기 신호 최우선 | 어느 단계에서든 EMG 놓기 신호가 즉시 override | EMG |

## **보조 채널 — 비전 기반 슬립 모니터링 (신규 추가)**

⑤ 단계(쥐고 있는 동안) Jetson을 완전히 놀리지 않고, 물체 표면의 시각적 특징점이 카메라 프레임 안에서 예상과 다르게 드리프트하는지 병렬로 감시한다. 이는 Present Current를 대체하는 게 아니라 이중 확인(cross-check) 역할이다 — 연구상 촉각/전류 기반 슬립 감지가 비전 단독보다 빠르고 정확하지만, 비전+촉각 융합이 둘 중 하나만 쓰는 것보다 항상 더 우수한 성능을 보인다. Present Current가 아직 못 잡은 미세한 슬립을 비전이 먼저 감지하면 EMG 힘 조절에 여유를 미리 확보할 수 있다. 이 유휴 시간에 Jetson은 다음 Center Bias 타겟도 미리 스캔해둘 수 있다.

# **8. 아직 열려 있는 지점**

* 인증 경계선 — 카본 소재·디스플레이 모듈의 의료기기 인증 범위 미확정
* 채널 우선순위 — 병원과 군, 초기 자원 배분 순서 미정
* 원가구조 — 계층별(3D프린팅 셸/카본 VIP/디스플레이) 원가·마진 숫자 미정
* 약지·소지 서보를 물리적으로 제거할지(텐던 공유) 여부 — 경량화 단계에서 데이터 기반으로 결정 예정
* ESP32↔Jetson 패킷의 정확한 바이트 포맷 및 타임아웃 값(ms) 확정
