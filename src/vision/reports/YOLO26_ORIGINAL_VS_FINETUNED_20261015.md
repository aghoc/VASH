# YOLO26 원본과 추가학습 모델 비교 — 2026-10-15

공식 원본 수치와 추가학습 모델을 같은 공개 test 및 공통 추론 조건으로 비교했다. 현재 롤백된 캔·동전 모델과 마지막 8종 추가학습 s 단독 모델의 평가를 새로 실행했다.

## 조건과 비교 대상

- 원본 s/m: 공식 COCO 80종 checkpoint. 가중치와 출력층을 수정하지 않았다.
- 캔·동전: `yolo26s_can_coin_retention.pt` — 현재 롤백된 15종 s 모델.
- 8종 추가학습 s: `yolo26s_focus8_refined_v8.pt` 단독. 마지막 배포의 원본 m 전문 모델 및 중앙 확대는 제외한다.
- 공통: RTX 4070 Ti SUPER CUDA:0, FP32, 640 square, rect=False, batch16, end2end=True, 단일 전체 화면.
- AP50–95×100, AP 평가 confidence 0.001, max_det=300. 정밀도/재현율은 confidence≥0.35, 정답 매칭 IoU≥0.5로 다시 계산했다.
- 평가 영역: frozen 6,103(EgoObjects 6,085 + LVIS 18), COCO 프로젝트 subset 125, Open Images 324. 모델마다 같은 이미지 항목과 공통 클래스 정답 수를 확인했다.
- 클래스 ID는 각 모델의 native 번호를 사용한다. 원본은 공통 8종 출력을 평가하고 추가학습 모델은 15종을 평가한다. 공통 클래스의 정답 box는 동일하다.
- 공개 분할은 이전에도 사용했으며 새 blind test가 아니다. 실제 ELP 또는 Jetson FP16 결과가 아니다. 미주석 물체가 FP로 집계될 수 있다.
- 새 학습·가중치 변경·배포 변경·카메라 사용 없음. 모든 checkpoint SHA-256 및 CUDA/end2end/정답 합계 확인 통과.

## 마지막 실제 배포 프로필과 혼동하지 않기

마지막 정확도 우선 배포는 위 추가학습 s 단독이 아니라, 7종에 원본 m의 클래스 재배치 전문 모델을 사용하고 펜/기타 클래스에는 추가학습 s와 중앙 확대를 적용한 조합이다. 연산량과 구성이 다르다.

공통 7종×3영역에서 당시 최종 조합과 이번 원본 m의 AP 차이 절댓값은 최대 0.18포인트다. 기존 보고서의 큰 개선 폭을 추가학습 s 자체의 효과로 해석하면 안 된다. 원본 m 담당 7종의 결과가 대부분이다.

두 추가학습 모델의 원본 대비 공통 클래스 AP 저하는 인식 능력 손상을 보여 준다. 과적합·기존 능력 망각·학습 라벨/도메인 차이 등 원인별 기여는 이 비교만으로 확정할 수 없다. 현재 두 배포는 사용자 ELP 시험에서 오탐으로 불합격했고 공개 AP로 그 판정을 대체하지 않는다.

frozen 칫솔은 정답 6개뿐이며 COCO 공은 2개뿐이다. Open Images 공은 정답이 없다. 캔/동전의 frozen 수치는 별도 캔·동전 공개 test 성능과 다르므로 서로 바꿔 쓰지 않는다.
