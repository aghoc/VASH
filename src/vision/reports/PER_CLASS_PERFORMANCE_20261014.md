## 현재 카메라와 저장 방식

사용자 요청으로 `vagt-camera.service`를 정지했다. 모델/설정은 그대로 배포되어 있다.
로그인 자동 시작 설정은 enabled 상태다. 다시 시작은 `systemctl --user start vagt-camera.service`.

현재 live viewer는 프레임을 디스크에 저장하지 않는다. 메모리의 최신 JPEG를 교체하며 스트리밍하고,
처리 시간 기록도 최근 120개만 유지한다. 6,587프레임은 처리 횟수이며 저장 파일 개수가 아니다.
`/snapshot.jpg`는 최신 메모리 JPEG 응답이고 서버에서 파일을 만들지 않는다.

`tools/record_ar_glass.py`를 별도로 실행할 때만 수집 이미지가 디스크에 저장된다.
기본값은 5프레임마다 저장, 최대 300장 후 종료이고 세션별 파일은 유지된다. 이번 작업에서는 별도 수집 프로그램을 실행하지 않았다.
Jetson `/mnt/data` SSD는 234GB 중 3.3GB 사용, 약 219GB 여유다.
