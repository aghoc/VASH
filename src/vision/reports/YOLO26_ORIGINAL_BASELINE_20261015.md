# YOLO26 공식 원본 성능 — 2026-10-15

추가학습하지 않은 공식 `models/pretrained/yolo26s.pt`와 `yolo26m.pt`를 새로 평가했다. 두 checkpoint는 80종 출력층과 가중치를 유지했고 평가 전후 SHA-256 일치를 확인했다. 이전 15종으로 출력층을 교체한 teacher나 v8 혼합 프로필의 결과를 원본 결과로 재사용하지 않았다.

카메라는 사용하지 않았고 배포 모델/임계값을 바꾸지 않았다. 학습 또는 threshold 선택도 수행하지 않았다.

## 평가 조건

- RTX 4070 Ti SUPER / CUDA:0, FP32, 640 square, batch16, rect=False, 단일 전체 화면, end2end=True.
- 모델은 80종 그대로다. 공통 8종의 출력만 평가하도록 필터하고 정답 class ID만 COCO ID로 변환했다. 원본 사진/라벨은 수정하지 않았다.
- 공개 test 이미지 항목 6,552개를 각 모델에 동일하게 사용: 기존 frozen 6,103(EgoObjects 6,085 + LVIS 18), COCO 125, Open Images 324.
- 공개 AP는 AP50–95×100이다. 인식 성공률(%)이 아니다. AP는 confidence 0.001부터 평가했다.
- 정밀도/재현율은 고정 confidence≥0.35, IoU≥0.5에서 예측을 다시 매칭해 계산했다. 평가기가 선택한 F1 동작점의 precision을 대체 사용하지 않았다.
- 정밀도=TP/(TP+FP), 재현율=TP/(TP+FN). 공개 라벨 기준이며 미주석 물체는 FP로 집계될 수 있다. 특히 Open Images 일부 클래스 주석의 누락 가능성을 고려한다.
- 기존에도 사용한 공개 분할이며 새 blind test가 아니다. COCO 125장은 val2017에서 만든 프로젝트 subset으로 공식 COCO 전체 benchmark 점수가 아니다.
