# EgoObjects 잔여 학습 프레임 감사

2026-10-15 KST. 사용자 제시 수치와 잔여분의 보강 가능성을 로컬 파일·라벨·원본 메타데이터 및 학습 기록으로 확인했다.
이번 작업은 감사와 보강안 정리이며 새 학습, 데이터셋 변경, 모델 교체, 카메라 재시작은 실행하지 않았다.

## 제시 수치는 맞음

| 비교 대상 | 이미지 수 |
| --- | ---: |
| `egoobjects_15` train의 EgoObjects 파일 | 49,830 |
| 현재 균형셋에 포함된 EgoObjects 파일 | 11,256 |
| 현재 균형셋에서 빠진 파일 | **38,574** |

균형셋은 `public_v3_adl_balanced_v2_15`, 현재 추가 학습셋은 `public_v4_can_coin_retention_15`다.
균형셋과 원본 train의 정확한 파일명을 비교한 결과와, 현재 추가 학습셋의 symlink를 실제 원본 경로까지 따라간 결과가 일치한다.
현재 추가 학습셋은 파일명 앞에 `base_`가 붙지만 실제 포함된 EgoObjects 원본은 동일하다.
`egoobjects_15`의 전체 train 49,946장과 다른 이유는 초기 LVIS 카드/블록 보완분 116장이 별도로 있기 때문이다.

## 최근 추가 학습에서 빠졌다는 의미

`artifacts/training/yolo26s_egoobjects_15/args.yaml`은 전체 `egoobjects_15`를 사용한다.
`results.csv`에는 완료된 epoch 17개의 기록이 있다. 이후 public-v2 단계는 이 단계의 `yolo26s_phase3.pt`에서 시작했다.
따라서 잔여 38,574장은 모델이 처음 접할 외부 데이터가 아니라, 초기 전체 학습 후 최근 추가 학습에서 제외된 기존 프레임이다.
최근 학습에 다시 섞는 것은 기존 클래스 표현을 유지·복원하는 실험으로 의미가 있으나 새 장면 38,574개가 확보되는 것과 같지는 않다.

선별 로직 `datasets/build_public_v2.py:link_base_focus`는 클래스마다 무작위 최대 1,000장을 뽑고 그 합집합을 사용한다(seed 42).
각 사진의 모든 라벨은 보존한다. 여러 물체가 함께 있는 사진 때문에 최종 클래스별 포함 이미지 수는 1,000장을 넘을 수 있다.

추가 클래스 양성 그룹은 현재 해당 클래스의 라벨이 포함된 train 그룹에 없던 그룹 수다.
같은 그룹의 다른 물체 라벨 사진이 현재 train에 있을 수 있어, 아래의 완전히 빠진 그룹 수와 구분한다.
상자·펜·리모컨·휴대폰·숟가락·열쇠 등의 보강 후보는 실제로 남아 있다.
칫솔·동전은 EgoObjects train에서 이미 모두 포함했고, 카드·작은 블록은 이 데이터의 변환 대상 taxonomy에 없다.

## 추가 프레임과 새 촬영 그룹의 차이

| 범위 | 이미지 | 원본 group_id | group_id + video_id |
| --- | ---: | ---: | ---: |
| 전체 EgoObjects train | 49,830 | 650 | 4,415 |
| 현재 포함 | 11,256 | 630 | 3,407 |
| 빠진 부분 | 38,574 | 642 | 4,329 |

- 현재 train에서 완전히 빠진 촬영 그룹은 **20개**, 해당 그룹의 잔여 사진은 **317장**이다.
- 현재 train에서 빠진 영상 조합은 **1,008개**다. 같은 물체 그룹의 다른 영상도 포함한다.
- 따라서 빠진 사진의 약 99.2%는 현재 포함된 그룹의 추가 프레임이다. 같은 그룹에서도 자세·가림·조명 차이는 보강에 도움이 될 수 있다.
- EgoObjects 원본은 동일 물체를 여러 조건과 방향에서 촬영하는 구조다. [공식 설명](https://github.com/facebookresearch/EgoObjects).

원본 경로와 group_id 기준으로 이 전체 train 후보가 현재 val/test와 겹치는 경우는 **0건**이었다.
이는 group/source-path 감사 결과다. 별도 파일에 같은 이미지가 복제됐는지 확인하는 byte/decoded-pixel hash 감사와 인접 프레임 유사도 검사는 아직 하지 않았다.

## 수정한 보강 우선순위

앞선 외부 공개 데이터 조사에서 로컬 잔여 프레임의 활용 가능성을 우선 검토하지 못했다. 다음 순서로 보완한다.

1. **로컬 EgoObjects 재활용부터 실험한다.** 이미 확보한 라벨과 파일을 사용하므로 새 촬영이나 다운로드가 필요 없다.
   누락 그룹과 클래스 양성 그룹을 우선하고, 같은 영상의 가까운 프레임 반복은 줄인다.
   현재 11,256장과 잔여 프레임을 고정된 한 subset에 묶기보다 epoch별로 촬영 그룹·클래스가 고르게 순환하도록 구성하는 방법을 검토한다.
2. 상자·펜·리모컨·휴대폰·숟가락·열쇠 등 필요한 클래스를 늘리되 병·상자 다수 프레임이 학습을 지배하지 않게 한다.
   기존 LVIS·ADL 및 캔/동전 공개 보강분을 함께 유지한다. 모든 38,574장을 그대로 붙이는 것은 파일 수 불균형을 다시 키울 수 있다.
3. **카드·작은 블록·칫솔은 외부 데이터 경로를 병행한다.** 이 잔여분에는 추가 양성이 없으므로
   카드 MIDV, Lego, 칫솔 COCO/Open Images 등의 앞선 후보가 여전히 필요하다.
   열쇠도 잔여 프레임 대부분이 기존 촬영 그룹이라 전용 데이터로 물체 다양성을 추가하는 편이 좋다.
4. GPU 재학습 시 현재 모델과 원래 15종 모델을 시작점 후보로 비교하고, 모든 클래스의 validation AP/P/R과 소형·가림 장면을 확인한다.
   기존 holdout은 보존하고 test를 후보 선택에 사용하지 않는다. 최종 모델만 Jetson FP16에서 검증한다.

재학습 전 성능 향상 폭은 확정할 수 없다. 이 잔여분은 우선 시도할 가치가 있는 기존 데이터 재활용 수단이다.
