# 요청 8종 정확도 우선 개선 결과 — 2026-10-15

**후속 실사용 판정: 불합격.** 같은 날 실제 ELP 화면 시험에서 사용자가 펜이 아닌 물체의 펜 오탐 과다를 확인했다. 카메라는 중지했고 자동 시작도 해제했다. 아래 공개 평가 수치는 보존하되 실사용 성능 합격의 근거로 사용하지 않는다. [문제와 평가 누락 기록](ELP_PEN_FALSE_POSITIVES_20261015.md).

공개 데이터 CUDA 추가 학습과 COCO 원본 전문 모델을 결합했다. 신규 카메라 프레임을 사용하지 않았다.
Jetson native TensorRT FP16 검증을 통과한 정확도 우선 프로필을 기본으로 반영했다. 고속 프로필과 이전 모델 복구 설정도 보존했다.

## 공개 test 결과

수치는 동일 CUDA FP32 / 640 square / rect=False / batch16의 AP50–95 × 100이며 단순 인식 성공률이 아니다. 물체별로 frozen·COCO·Open Images 영역을 같은 비중으로 평균했다. COCO에 펜 정답이 없어 펜은 frozen·OI 두 영역 평균이다. 아래 test는 기존에도 보고에 사용한 공개 분할이며 새로운 blind test가 아니다. 후보 선택은 이번 validation에서 완료했으며 test를 보고 조합을 바꾸지 않았다.

## 학습·선택과 개선 원인

- RTX 4070 Ti SUPER에서 기존 공개 train 원본 12,150장과 train crop 780개를 재사용했다. 신규 원본 사진을 다운로드해 학습한 것으로 세지 않는다.
- 출력 행만 학습 6 epoch와 분류 특징까지 학습 4 epoch를 비교했다. backbone/neck/box와 모든 BN 통계를 처음부터 고정했다.
- 세 validation 영역과 can/coin 보존 기준에서 classifier 마지막 epoch를 선택했다. test는 선택에 쓰지 않았다.
- 공식 COCO 사전학습 YOLO26s/26m을 프로젝트 class ID에 정확히 재배치해 비교했다. 신규 추가 학습 모델과 원본 사전학습 모델을 혼동하지 않는다.
- 기존 fine-tuning 모델보다 원본 COCO 가중치의 7종 성능이 높아, 추가 학습 중 일반 물체 인식 능력이 약해진 것으로 판단했다. 단순 데이터 수 증가 외에 기존 능력 보존이 필요했다.
- 최종 전문 모델: `yolo26m_focus8_coco_teacher_v8.pt`, views=`center`, strategy=`route`, small_primary_size=`0`.
- 7종은 공개 전문 모델, 펜과 나머지 클래스는 추가 학습 모델이 담당한다. 각 모델의 end-to-end head는 유지하며 뷰·모델 간 중복 정리는 별도 CUDA 병합이다.
- 원본+중앙 확대/4방향 확대, 전문 모델 route/union, 32/64px 작은 칫솔 보존 규칙을 validation에서 비교했다. 단순 합치기나 더 많은 crop이 항상 더 좋지 않았다.

## 한계와 다음 보완

펜과 극소형 칫솔은 여전히 약하다. 특히 기존 frozen 칫솔은 정답 수가 매우 적고 물체가 작아 일반 공개 사진에서의 개선과 다를 수 있다. 각 물체/영역의 하락도 위 표에 그대로 공개했다. 공개 데이터 점수는 한국 실사용 환경의 정확도를 보장하지 않는다.
미사용 COCO train 후보를 기존 라이선스·crowd 제외·중복 규칙으로 감사했을 때 총 1480장, 숟가락 0·포크 0·칫솔 1개 양성 사진에 그쳤고 리모컨은 없었다. Objects365는 공식 학술 이용 조건과 등록 절차가 있어 임의 미러로 확보하지 않았다. 추가 원본 수를 단순히 늘리는 것보다 촬영 도메인·크기·라벨 품질을 맞추는 것이 남은 과제다.
