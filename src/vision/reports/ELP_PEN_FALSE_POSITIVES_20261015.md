# ELP 실시간 시험 중단: 펜 오탐 — 2026-10-15

v8 정확도 우선 프로필은 실제 ELP 시험에서 **실사용 불합격**이다. 사용자가 펜이 아닌 여러 물체가 펜으로 검출되는 문제를 확인했다. 공개 AP 개선만으로 실사용 배포가 적절하다고 판단한 것은 충분한 검증이 아니었다.

## 종료 확인

- 사용자의 요청으로 실제 카메라 화면을 열었고, 이후 사용자가 “그만”이라고 지시해 즉시 종료했다.
- `vagt-camera.service`: inactive/dead, MainPID=0, UnitFileState=disabled.
- 종료 점검에서 프로젝트 카메라 프로세스 및 영상 장치 점유 PID 출력 없음. 로컬 SSH 영상 터널도 종료했다.
- 이 시험에서 프레임/영상 자동 저장이나 데이터 수집을 실행하지 않았다. 뷰어는 최신 JPEG를 메모리에서 교체한다.
- 향후 카메라는 사용자가 다시 요청할 때만 켜고, 사용자가 완료/중지할 때 끈다. 임의로 짧은 시험 시간을 정하지 않는다.

## 확인한 사실

- 실제 입력은 1280×720 YUYV/요청 60 FPS다. 시험 중 상태 확인 시 870프레임, 읽기 실패 0, 화면 포함 처리 약 10.25 FPS였다. 이는 물체 인식 정확도를 뜻하지 않는다.
- 배포 프로필의 펜 검출 기준은 공통 confidence 0.35다. 펜 전용 기준은 없었다.
- COCO 전문 모델 담당은 병·컵·휴대폰·리모컨·숟가락·포크·칫솔 7종이다. 펜은 추가학습 모델의 전체 화면 및 중앙 확대 검출을 사용한다.
- 공개 test의 펜 AP50–95×100은 22.86→24.37로 개선이 작았다. Open Images test에서는 28.92→28.63으로 소폭 하락했다.
- 모델 선택 코드의 기준은 공개 영역/클래스 AP와 기존 캔·동전 보존이다. **실제 배포 기준 0.35에서 펜 오탐 허용량과 비대상 물체에 대한 오탐 평가가 합격 조건에 없었다.**
- 저장된 validation precision은 평가기가 고른 동작점의 값이다. 이를 실사용 confidence 0.35의 precision이나 실제 카메라 정확도로 해석하면 안 된다.

## 아직 확정하지 않은 원인

사용자가 확인한 펜 오탐은 분명한 실패다. 다만 이 관찰만으로 과적합을 확정하거나, 모델 전체가 이전보다 퇴행했다고 정량 결론 내릴 수는 없다. 학습/검증 분포 차이, 비대상 물체 다양성·라벨 품질, 중앙 확대의 펜 오탐 증폭, confidence 보정 실패를 분리 확인해야 한다. 카메라 화면을 정답 데이터로 저장해 비교한 실험은 없다.

## 재검증에 필요한 조건

같은 공개 validation 이미지로 기존/v8 단일/v8 중앙 확대의 펜 검출을 비교하고, 펜 정답이 충분히 표시된 비대상 장면에서 고정 confidence별 precision·recall·장면당 오탐을 함께 측정한다. 부분 라벨 데이터의 “펜 라벨 없음”을 곧바로 “실제 펜 없음”으로 취급하지 않는다. 임계값 조정은 실제 펜 누락과 함께 평가해야 하며, 오탐 화면만 숨긴 것을 모델 개선으로 세지 않는다. 이후 사용자가 요청하는 실제 ELP 시험을 통과하기 전에는 실사용 합격으로 표시하지 않는다.

이번 중단 뒤 추가 카메라 촬영, 가중치 변경 또는 추가 학습은 실행하지 않았다. 기존 공개 평가 원본과 모델은 비교를 위해 보존한다.
