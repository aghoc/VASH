# YOLO26 공식 원본의 안경 시점 적합성 판단 — 2026-10-15

후속 결정(2026-10-16): 사용자가 시연 범위를 성능이 좋은 3~5종으로 축소했다. 원본 m을 Jetson native FP16으로 검증·적용하고 원본 80종 전체 표시로 실제 안경 카메라 시험을 시작했다. 포크·리모컨·휴대폰은 시연 후보이며 화면을 3종으로 제한하지 않는다. 아래 15종·4그립 판단은 초기 전체 설계에 대한 기록이다. [현재 배포와 검증 결과](ORIGINAL_DEMO_DEPLOYMENT_20261016.md).

현재 근거로 공식 원본은 **지원 물체에 한정한 안경 시점 검증용 기준 모델로 적합한 후보**다. 다만 **목표 15종과 4종 그립을 모두 지원하는 최종 단독 인식 모델로는 부족**하다. ELP를 실제 안경 위치에 장착한 원본 모델의 중앙 타깃 정확도·오탐·미검출·처리 지연 합격 여부는 아직 확인하지 않았다.

## 판단 근거

공식 원본 s/m과 두 추가학습 s 모델을 같은 공개 이미지와 CUDA FP32/640 square/batch16/end2end/단일 화면으로 비교했다. 요청 공통 7종 평균 AP50–95×100은 다음과 같다. 원본에서 미지원인 펜은 평균에서 제외했다.

| 평가 영역 | 원본 s | 캔·동전 학습 s | 마지막 8종 학습 s | 원본 m |
|---|---:|---:|---:|---:|
| EgoObjects 중심 frozen 6,103장 | 34.23 | 25.01 | 25.85 | 41.91 |
| COCO 프로젝트 subset 125장 | 42.76 | 19.44 | 22.29 | 49.47 |
| Open Images 324장 | 64.68 | 29.23 | 36.74 | 69.42 |

frozen 6,103장은 EgoObjects 6,085장과 LVIS 18장이다. EgoObjects는 Aria, Ray-Ban Stories, Vuzix Blade 등 스마트안경과 눈 근처에 둔 휴대전화로 촬영한 1인칭 데이터다. 따라서 해당 평가를 안경 시점의 간접 근거로 사용하는 것은 타당하다. 다만 공개 데이터의 장치·광학·촬영 상황은 현재 ELP 장착 상태와 다르며, 이 프로젝트 분할은 EgoObjects 공식 전체 benchmark도 아니다. [EgoObjects 원 논문](https://arxiv.org/html/2309.08816v1).

## 물체별 현실적인 기대

정밀도/재현율은 공개 정답 기준 confidence≥0.35, IoU≥0.5다. 미주석 물체도 FP로 집계될 수 있어 실제 ELP 오탐률과 동일하게 해석하지 않는다. 아래 판정은 측정값에 대한 해석이며 실사용 합격 판정이 아니다.

| 물체 | 원본 s 정밀도 / 재현율 % | 원본 m 정밀도 / 재현율 % | 판단 |
|---|---:|---:|---|
| 병 | 50.2 / 50.7 | 50.7 / 56.3 | 원본도 오탐과 미검출이 남아 있음 |
| 컵 | 51.8 / 69.2 | 51.9 / 73.2 | 검출은 비교적 많으나 정밀도 검증 필요 |
| 휴대폰 | 60.8 / 34.5 | 64.1 / 44.6 | 미검출 비중이 큼 |
| 리모컨 | 80.9 / 34.8 | 76.5 / 44.6 | 시연 후보이나 놓치는 경우가 많음 |
| 숟가락 | 46.7 / 18.0 | 56.0 / 24.8 | 현재 근거로 안정적 사용을 기대하기 어려움 |
| 포크 | 81.7 / 47.8 | 87.2 / 79.9 | 특히 m에서 가장 유망한 요청 대상 |
| 칫솔 | 0.0 / 0.0 | 0.0 / 0.0 | 정답 6개뿐이어서 충분한 판단 근거 없음 |
| 공(sports ball) | 91.5 / 29.0 | 92.1 / 49.9 | 검출 정밀도는 높으나 미검출이 남음 |

칫솔은 별도 COCO에서 s/m AP 40.45/52.26, OI에서 58.93/54.35였다. frozen 6개에서 AP 0인 사실을 칫솔 전체 인식 능력 0으로 일반화하지 않는다.

원본은 목표 중 병·컵·휴대폰·리모컨·숟가락·포크·칫솔·스포츠공 8종을 직접 지원한다. 펜·캔·동전·상자·카드·열쇠·작은 블록은 공식 출력 클래스에 없다. 이 제한은 원본에 입력 해상도·threshold·시간 안정화만 조정해서 해결할 수 없다. [공식 COCO 클래스 목록](https://docs.ultralytics.com/datasets/detect/coco/).

현재 프로젝트의 `configs/grip_map.yaml`에 따르면 지원 물체는 POWER와 TRIPOD 그룹에 해당한다. PINCH의 동전/작은 블록, LATERAL_PINCH의 카드/열쇠는 원본이 지원하지 않으므로 4종 그립 전체를 원본 단독으로 시연할 수 없다.

## 안경 시점 시스템에서 남은 확인

- 목표 선택: 계획서의 목표는 중앙 타깃 선택 정확도 95% 이상이다. 공개 정지 이미지의 AP/P/R은 이 수치가 아니다. 원본의 실제 중앙 타깃 선택 성공률, 오잠금, 불필요한 전환과 획득 시간을 아직 측정하지 않았다.
- 영상 안정성: 현재 5프레임 중 4표와 IoU 기반 안정화는 일시적인 출력 변동을 줄이는 구조다. 같은 오탐이 지속되는 경우에도 잠금이 가능하므로 오탐 제거를 보장하지 않는다. 안경 움직임·손 가림·다중 물체 조건에서 확인해야 한다.
- 실시간성: 계획서의 Jetson end-to-end p95 지연 목표는 50 ms 이하다. 이번 원본 수치는 RTX FP32 이미지 평가다. 원본 s/m 각각의 Jetson FP16 전체 파이프라인 속도는 이 평가에서 측정하지 않았다. 이전 혼합 프로필의 13.56 FPS나 추가학습 s의 카메라 FPS를 원본 속도로 옮겨 쓰지 않는다.
- 연결: 현재 실행 코드와 설정에 원본 가중치 경로만 넣는 것은 충분하지 않다. 원본 COCO의 `cell phone`→프로젝트 `phone`, `sports ball`→`ball` 이름/ID 연결, 지원 8종 출력 필터, 현재 can/coin 전용 threshold 정리가 필요하다. 이는 출력 연결 작업이며 추가학습은 아니다. 원본 80종 가중치와 출력층은 유지할 수 있다.
- 영상 크기: 이번 비교는 square640이다. 현재 라이브 단일 모델 경로의 rectangular 전처리 및 카메라 입력과 조건이 같다고 간주하지 않는다. 실제 시험에서 사용한 전처리를 기록해야 한다.

`reports/phase8_status.json`은 예전 Pixy/장착 전 준비 상태를 기록한 문서다. 현재 ELP가 없다는 증거로 재사용하지 않았다. 최신 ELP 서비스와 두 추가학습 모델 시험은 별도 기록에 있으며, 사용자의 요청으로 카메라는 정지 상태다.

## 권고

추가학습을 재개하기보다 공식 원본을 고정한 상태로 지원 8종의 실제 안경 시점 검증을 먼저 진행하는 편이 타당하다. 원본 s는 현재보다 나은 기준 모델이며, 원본 m은 특히 포크 등에서 정확도 후보로 가치가 있다. 최종 s/m 선택은 같은 실제 장면의 중앙 타깃 성공률과 Jetson FP16 전체 지연을 함께 보고 결정한다. 원본 m의 높은 공개 AP만으로 m 배포를 확정하지 않는다.

새 학습 데이터셋 구축을 적합성 판단의 선행 조건으로 요구하지 않는다. 사용자가 화면을 보며 목표 물체의 올바른 선택·오탐·미검출을 확인하는 실사용 검증부터 할 수 있다. 향후 시험에서는 사용자의 시작 요청 후 실제 화면을 보여 주고, 사용자가 종료를 지시할 때까지 유지한다. 이번 판단 작업에서는 카메라를 켜거나 배포/임계값을 변경하지 않았다.
